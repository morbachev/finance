# Finance v1.1.3：取込画面・明細管理・OneDrive接続画面の整理

Finance v1.1.2に重ねる差分パッチです。OneDriveの年別データ構造、AES-256-GCM、PBKDF2、ETag自動マージ、PDF原本保存、旧IndexedDBの移行経路は変更しません。

## 変更内容

### 1. インポート画面は今回の下書きだけ

- OneDriveから復号した保存済みの明細は、インポート画面には並べません（明細管理では従来どおり確認可能）。
- 今回取り込んだPDF/Web明細と解析失敗項目だけを一覧に表示します。
- 一括保存が成功した明細はインポート一覧から外し、プレビューも初期状態へ戻します。保存失敗時は下書きを維持します。
- 過去に保存済みの同一カード・同一月を再インポートして修正する場合は、取込待ちに表示し、再保存後は一覧から外します。
- 取込下書きの「除外」や「下書きを破棄」は、**クラウド上の保存済み明細を削除しません**。再インポートで作成した変更下書きを破棄した場合は、OneDriveの保存済み状態へ戻します。
- 空の一覧をコンパクトにし、対象がない場合は一括保存ボタンを無効にして「取込対象はありません」と表示します。

### 2. 明細の管理：今月を初期表示

- 初期フィルターはブラウザの**現地暦の年・月**です（例：2026年11月なら「2026年」「11月」）。
- その年月の明細がまだ存在しなくても選択肢に表示します。年を変更した際は月が「すべての月」に戻る従来の操作を維持します。
- 他の年・月の明細や年月不明の明細は、「すべて」の選択肢で引き続き表示できます。

### 3. OneDrive画面：日常操作を優先

- 主要領域にMicrosoftアカウント、保管庫の状態、最新データ取得、ロック、サインアウトを集約。
- 初期設定（Client ID・リダイレクトURI）、保存先接続確認、旧データ移行、暗号化送受信テストを折りたたみに移動。
- Client IDを初めて登録する場合に限り、設定欄を自動展開。設定済みなら通常は折りたたまれます。
- Microsoft Graph連携や各操作ボタンの要素IDは維持し、ログイン・保存・復号のロジックは変更していません。

## Macでの適用

```bash
cd ~/Documents/finance || exit 1
unzip -o ~/Downloads/finance-v113-ui-refresh.zip -d ~/Documents/finance
npm run check
npm run test
npm run verify:cloud
```

ブラウザを `⌘ + Shift + R` で強制再読み込みしてください。既存のOneDrive保管庫の移行、データの削除、Microsoft Entraでの再登録は不要です。

## 検証

- TypeScript型チェック成功
- 自動テスト95件成功（前版90件＋今回5件）
- Chromiumで取り込み待ちのみの表示・下書き破棄・**模擬OneDriveへの保存成功による一覧消去**を確認
- 2026年11月の暦初期値、OneDrive詳細設定の開閉、Mac幅1440px・Galaxy幅390pxの表示を確認
- 実際のMicrosoft Graph通信と実データでの検証は利用者環境で行ってください

**注意：** 取込途中の未保存データはブラウザのメモリにのみ存在するため、保存前にページを閉じると消える可能性があります。保存済み明細は「明細の管理」で確認してください。
