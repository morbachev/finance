# Finance v0.8.3 UIパッチ

v0.8.2 の `~/Documents/finance/` に適用してください。

## 変更点

- STEP 02: 明細一覧をPCで550px（概ね6件分）に拡張。スマホ幅では490pxに調整。
- STEP 02: 解析失敗・要確認 → 暫定明細 → 照合OK、の順で表示。各状態内では従来の登録順を維持。表示順だけの変更であり、保存データ・選択中のID・削除インデックスは変更しません。
- STEP 03: 「✓ 明細の合計額が請求額と一致しています。」をカード情報・請求月・支払日・取引件数の下に移動。エラー・注意文は従来の場所に残します。
- STEP 03: 取引テーブルの利用日と当月請求額に昇順/降順の切替を追加。初回押下は昇順、再押下で降順。別列を押すとその列の昇順。数値は数値として、日付はISO日付として比較。同値は原本順を維持。実際のデータを入れ替えたり保存内容を変更したりしません。

## 適用

```bash
cd ~/Documents/finance
unzip -o ~/Downloads/finance-v083-patch.zip -d ~/Documents/finance
npm run check
npm run test
```

既に起動中の `python3 -m http.server 5173 --directory dist` は再起動不要。Macのブラウザで `⌘ + Shift + R`。

## 動作確認

- 一覧に暫定/要確認/照合OKを混在させて、要確認が先頭になること。
- 一覧の項目を押すとSTEP 03が対応する明細に切り替わること。
- 日付・金額のヘッダーの矢印を2回押し、昇順→降順になること。
- 明細の管理画面や再表示時に元の取引データが変更されていないこと。

解析器・暗号化・一括保存のソースは変更していません。
