# Finance v0.8.4 — UI調整パッチ

v0.8.3を前提にした軽量なUIパッチです。`src/` 内の解析・暗号化・保存ロジックは変更していません。

## 変更内容
- STEP 01: 「PDFファイル」「Web明細の貼り付け」の重複見出しを削除。入力欄のアクセシブルなラベルは維持。
- Web明細貼り付け欄のプレースホルダーを「Web明細をここに貼り付け」に簡素化。
- STEP 02: 「取込中・保存済みの明細」見出しを削除。「下書きを破棄」を件数の右隣へ移動。
- STEP 02のカラムをやや広くし、STEP 03を少し狭めた。小画面では従来どおり縦積み。
- サイドバー表示のバージョンを0.8.4に更新。

## 適用

ZIPをダウンロードフォルダに保存したうえで：

```sh
cd ~/Documents/finance
unzip -o ~/Downloads/finance-v084-patch.zip -d ~/Documents/finance
npm run check
npm run test
```

適用後、ブラウザで `Cmd + Shift + R` で更新してください。

## 注意

- パッチには `node_modules`、PDF.jsライブラリ、個人データは含まれていません。
- テストはNode.js上の既存22件です。ブラウザの実レイアウト操作はMacで最終確認してください。
