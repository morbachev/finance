# Finance v0.8.5 UIパッチ

v0.8.4から適用する差分です。TypeScript + HTML/CSSの構成、暗号化保存、PDF解析、一括取込処理は維持しています。

## 修正内容

- **要確認明細の削除:** エラーを含む明細のゴミ箱を押すと確認なしで削除（保存済みの要確認明細も対象）。正常・暫定明細は従来どおり確認あり。PDF解析失敗の行も即時除外。
- **明細の管理:** STEP 01に年月フィルターを追加。請求月を持つ実データから年と月の選択肢を生成。年月を降順表示、同じ年月のカードは元の順序を維持。該当がない場合は空状態を表示。「すべての年」を選べば請求月未取得の明細も表示。
- **共通カード部品:** 取込画面と管理画面で同じTypeScriptの明細カード生成関数・同じCSSスタイルを利用。状態ラベル、保存状態、選択枠、余白を共通化。
- **管理画面:** STEP 01「明細一覧」、STEP 02「選択中の明細」。取込画面に戻るボタンを廃止（サイドナビから切り替え）。
- **金額入力欄:** 請求総額と取引明細の金額欄を右寄せ（等幅数字）に変更。
- **パフォーマンス:** 管理画面が非表示の間は管理一覧を再描画しないように調整。

## 適用手順

ZIPをダウンロードして `~/Downloads/finance-v085-patch.zip` に保存した場合：

```bash
cd ~/Documents/finance
unzip -o ~/Downloads/finance-v085-patch.zip -d ~/Documents/finance
npm run check
npm run test
```

既存のPython Webサーバーは再起動不要です。ブラウザで `⌘ + Shift + R` を押して更新してください。データベースや保存済み明細の内容は変更しません。
