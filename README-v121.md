# Finance v1.2.1：最近の利用先選択＋カテゴリーと12色パレット

Finance v1.2.0を前提とするUI・ルール拡張パッチです。**OneDriveの暗号化ファイル形式の識別子・保存パス・金融明細の解析元データは変更しません。**

## 追加した機能

### 利用先を履歴から選ぶ
- 利用先ルール画面の「カード明細に記載される利用先」の隣に「履歴から選ぶ」を追加。
- OneDriveから読み込んでいる**保存済みカード明細の元の利用先表記**を、直近利用日順で一覧表示。入力済みルールの表示名や個別表示名ではなく、カード会社の元表記を利用します。
- モーダルでは「すべてのカード／特定カード」の絞り込みと、利用先名の文字列検索に対応。カードごとに同じ利用先が複数ある場合はまとめ、最終利用日と利用件数を表示します。
- 項目をクリックするとルール登録の利用先欄に入力。表示名やカテゴリー欄など他の入力内容は保持。最大60件を描画し、検索で絞り込めます。
- 対象は現在開いている保管庫から取得したデータ。新しい通信やIndexedDBアクセスは行いません。

### カテゴリーと色
- 12カテゴリー：**食費、サブスク、固定費、資産形成、日用品、交通費、住居・光熱、通信費、医療・健康、趣味・娯楽、交際費、その他**。
- 利用先ルールごとにカテゴリーを任意設定できるように変更。ルールに一致する過去・今後の取引に対して、表示時にカテゴリーを適用します。
- 明細インポートのプレビュー、明細の管理、登録済みルールにカテゴリーの色付きラベルを表示。元の利用先や金額は書き換えません。
- カテゴリーの色は**青・藍・紫・桃・赤・橙・琥珀・黄・緑・青緑・灰・茶**の12色からのみ選択できます。自由なHEX入力はありません。
- ルール画面右下の「カテゴリーの色を設定する」を開き、カテゴリーごとに色を変更できます。色は同じカテゴリーのすべての取引に反映されます。

### 保存と互換性

```text
OneDrive / Apps / 共通アプリ/
└── finance/
    ├── index.enc
    ├── statements/YYYY.enc
    ├── originals/YYYY/MM/UUID.enc
    └── rules/merchants.enc   ← 既存ファイルに任意フィールドを追加
```

- 新しいOneDriveファイルは**増やしません**。既存の`merchants.enc`の暗号化JSONに、ルールごとの任意`categoryId`と、カテゴリー別の任意`categoryColors`を追加します。
- 既存のv1.2.0の暗号化ルールファイルもそのまま読み込み可能。新しいカテゴリーを登録するまでは旧データを変えません。
- カテゴリーとカテゴリー色は**ルールファイルだけを保存**するため、過去年度の`statements/*.enc`とPDF原本を再保存しません。
- カテゴリー・色の競合はOneDriveのETagと3方向フィールドマージで統合し、同じ項目の同時編集では元の選択肢が暗号化競合履歴に残ります。
- **古いv1.2.0のアプリでルールを編集して保存すると、新しい任意フィールドが失われる可能性があります。MacとGalaxyの両方をv1.2.1に更新してからカテゴリーを運用してください。**
- 同じ利用先に異なるカテゴリを割り当てたい場合、今回はルール単位のカテゴリーであるため、取引1行だけのカテゴリー上書きUIはまだありません。次回の改善候補です。

## Macへの適用

```bash
cd ~/Documents/finance || exit 1
unzip -o ~/Downloads/finance-v121-merchant-categories.zip -d ~/Documents/finance
npm run check
npm run test
npm run verify:cloud
```

適用後にブラウザで`⌘ + Shift + R`。Microsoft Entraの再設定やOneDriveファイル移行は不要。
