# Finance v1.2.6 | OneDrive暗号保管庫の読み取り専用診断

## 目的
v1.2.5でパスフレーズ変更後、クラウド保管庫の復号・再読込時にJSON解析エラーが発生したケースを調査するための**診断用パッチ**です。原因が確定していない段階でデータを自動修復・削除・再暗号化しません。

## 使い方
1. v1.2.5に差分ZIPを上書きし、Mac側で `npm run check && npm run test && npm run verify:cloud` を実行。
2. FinanceでMicrosoftアカウントに接続する。**保管庫のロック解除は不要**。
3. 「OneDrive」→「接続設定・メンテナンス」→「保管庫を診断（読み取り専用）」へ進む。
4. **診断用パスフレーズ**に変更後のパスフレーズを入力すると、索引・年別明細・利用先ルール・資産設定の復号整合性まで検査する。空欄なら暗号ファイルの外側JSON・保存先のみを確認する。
5. 「診断結果をコピー」でメッセージのみ共有。パスフレーズ、ファイルID、明細、暗号文、トークンなどは結果に含めない。

## 安全性と制限
- 診断機能はMicrosoft Graphに対して**読み取り専用**で動作し、OneDrive上のデータを変更しません。
- パスフレーズはブラウザ内の鍵導出にのみ使い、診断終了時に入力欄を消去します。Graphにも送信しません。
- 復号する場合でも明細本文や金額をログとして記録・表示しません。
- PDF原本の復号や明細の実データ完全性、Graphの実サービスとの疎通まで保証するものではありません。
- パスフレーズ変更や復元処理には手を加えていません。原因判明までは変更のやり直し、旧世代ファイルの削除、手作業の上書きを避けてください。
