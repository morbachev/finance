# Finance v1.2.7 | パスフレーズ変更後の追加診断

## 目的
「索引の外側JSONは正常だが、索引だけ復号できない」という診断結果に対し、**索引が復号できなくても検査を打ち切らず**、変更後の暗号化世代にある年別明細・利用先ルール・資産設定を独立に読み取り・復号検査します。

## 操作
1. v1.2.6へ差分ZIPを上書き適用、再読み込み（⌘+Shift+R）。
2. OneDrive画面の「接続設定・メンテナンス」から、診断欄へ**変更後に設定したパスフレーズ**を手入力。
3. 「保管庫を診断（読み取り専用）」を押し、「診断結果をコピー」で結果を共有。
4. 診断結果のみ共有。**変更前のパスフレーズでは現在の新世代を検査できない**ため、旧パスフレーズの入力は不要です。文字列そのものは決して共有しない。

## 結果の読み方
- 「索引の復号：失敗」かつ「索引以外の独立復号：1件以上成功」：入力したパスフレーズは少なくとも一部の新世代暗号ファイルに一致。索引自体の暗号データ・ソルト・保存結果を優先調査。
- 「索引の復号：失敗」かつ「索引以外の独立復号：0件成功」：入力文字列の相違、保存内容の異常などが考えられます。**パスフレーズ違いと確定はできません。**
- 新しい世代に検査対象ファイルがない場合：索引と入力文字列のどちらが原因か判断できません。

## 安全性
- Graph APIは読み取り処理のみ。暗号ファイルへの書き込み・移動・削除・自動修復は一切ありません。
- 索引が復号できないとき、個々のファイルのソルトから一時鍵を導出して検査し、平文内容は報告しません。パスフレーズ、キー、トークン、明細・金額、ファイルIDを診断に含めません。
- **復旧・パスフレーズ再変更・旧世代の削除は実行しない**。OneDrive上の元データをそのまま保持してください。
- 復号整合性のテストは模擬Graphを使います。実アカウントの通信・復号成功はユーザー端末で確認が必要です。
