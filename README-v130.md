# Finance v1.3.0 | 設定の統合・自動残高予測

適用元：**Finance v1.2.9**。必ずこのバージョンまでのパッチを適用済みのプロジェクトへ上書きしてください。Mac / Galaxyなど、同じ保管庫を使用する端末は、**両方をv1.3.0に更新**してからNISAのカード連携を保存してください（旧版で資産設定を更新すると新しい連携欄が失われる可能性があります）。

## 画面の変更

- サイドバーの「OneDrive接続」と「資産・定期入出金」を統合し、単一の「設定」ページに変更。
- 設定ページの上部が「口座残高」「NISAカード積立」「定期入出金」。表示設定（ライト/ダーク/システム）をこのページに移動。その下に「アプリ・OneDrive」の接続、同期、ロック、暗号化パスフレーズ変更、診断・メンテナンスをまとめました。
- 重複する保管庫の説明を減らし、パスフレーズ変更の注意点など重要なセキュリティ説明は維持。
- 楽天銀行を「メイン口座」グループ、現金貯金とNISAを「貯蓄・投資資産」グループに分けたまま、十分な幅があるPCでは3枚を横並びにします。画面幅が狭い場合は自動で2列・1列に変わり、横スクロールしません。
- 日時入力のコンパクトさ、一括保存、残高履歴、定期入出金の編集操作は維持。

## 残高の計算

- 手入力した口座残高と日時は、そのまま**確認済み残高の記録**として保存します。フォームは次回も空欄のままで、新しい確認値だけ入力します。
- カードや銀行からの取引が確定したことを確認する機能はありません。表示するのは**現在の推定残高**と**来月末の参考予測**です。最後の確認済み残高の日付より**翌日以降**に発生する、設定済みの定期入出金・口座間振替を自動加減します。確認日当日の予定は二重計上防止のため加減しません。
- 月次 / 年次 / 週次の繰り返し、月末、31日がない月の月末繰上げ、開始・終了期間、停止中設定を反映します。楽天銀行から貯金への振替は双方で相殺されるので、全体資産を増やしません。
- ページを開き直した場合や日付が変わった場合は、読み取り専用で表示を再計算。予測の更新はOneDriveへの書き込みを発生させません。
- 確認済み残高がない口座は予測できません。長期間の積み上げ誤差を避けるため、確認済み残高から10年を超える予測は表示しません。

## NISAのカード積立連携

- 折りたたみ「NISAのカード積立を連携」で対象カードと、明細の**元の利用先に含まれる文字列**（3文字以上）を指定して保存します。デフォルトは**未連携**で、すべてのカード利用を勝手にNISAに加算しません。
- 保存済みカード明細のうち、対象カード・元の利用先文字列が一致する**プラスの金額の取引**だけを、利用日基準でNISAに加算します。同じ明細が二重読み込みされてもID単位で二重計上しないよう保護します。
- NISAの推定額は手入力した実際の評価額を起点に積立額を加算した**参考値**です。基準日より後の運用損益や売却益は自動推定しません。
- 積立に使ったクレジットカードの銀行引落は、この機能では差し引きません。カードによって引落元口座が異なるためです。**同じNISA積立を定期入出金にも登録すると二重加算**になるので避けてください。
- 保存先は従来の `finance/settings/assets.enc`。暗号化形式とOneDriveフォルダ構成は変更せず、内部資産データに任意の連携欄を追加して旧データも読めるようにしています。

## まだ未対応・実機での確認

- **Payrollの実際の給与収入を読んで楽天銀行へ加算する機能は未対応**。Payroll側の最新保存形式・暗号化鍵・収入データの仕様を確認してから実装します。給与の仮額を勝手に加算しません。
- クレジットカードの各引落口座と、みずほ銀行への毎回異なる金額の送金についても未対応。楽天銀行からすべてのカード請求額を引くと誤計算になるため、保留しています。
- 定期入出金の変更は、確認残高以降の推定計算にも反映されます。実際の銀行引落金額や停止・変更が発生した場合は、残高を再確認して登録し直すのが確実です。
- Microsoftアカウントを用いたGraphの実通信はこの環境では実行していません。設定保存・別端末同期・パスフレーズ再解除はMac/Galaxyで確認してください。

## Macへの適用

```bash
cd ~/Documents/finance || exit 1
unzip -o ~/Downloads/finance-v130-unified-settings-forecast-patch.zip -d ~/Documents/finance
npm run check
npm run test
npm run verify:cloud
```

`dist/`を同梱しているためGitHub Pages更新時にもコミット対象です。適用後ブラウザを`⌘ + Shift + R`で再読み込み。
