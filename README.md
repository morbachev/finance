# Finance v1.6.4

カード明細・口座残高・入出金・資産形成をまとめて管理する、個人向けのブラウザアプリです。HTML / CSS / TypeScriptで構成し、明細PDFと金融データはブラウザで処理します。永続データの保存先には、Microsoft OneDriveの暗号化保管庫を使用します。

## 主な機能

- **明細インポート**：カード会社のPDFやWeb明細を解析し、確認してからOneDriveに保存。PDF原本も暗号化して保管します。
- **明細管理**：年月別の明細検索、利用日・利用先・金額・補足などの確認と編集、原本PDFの取得。原本のダウンロード名は `YYYYMM_カード種別_明細.pdf` 形式です。
- **ルール・カテゴリー**：複数の利用先表記に共通の表示名・カテゴリーを付与。完全一致・前方一致・部分一致に対応します。
- **月別サマリー**：カード請求、定期・単発の入出金、Payrollの給与実績・見込みを集計。楽天銀行の残高推移と、引落日ごとの残高不足も確認できます。
- **口座管理**：楽天銀行・みずほ銀行・現金貯金口座・NISAの残高履歴、定期入出金、単発の入金・支出・振替・現金引出を管理します。
- **カード引落口座・みずほ送金予測**：カードごとの引落口座を指定。楽天銀行からみずほ銀行へカード代金を送金する予定を、請求額に基づき試算します。実際の送金は行いません。
- **資産予測**：現金貯金・NISA・合計の将来推移を表示。目標年齢・想定年利を変更し、積立額を変えた場合の差も試算できます。
- **Payroll連携**：別アプリPayrollの解析済み給与情報を読み込みます。Financeが給与明細PDFを直接解析する仕組みではありません。

予測や見込みは、登録した残高・予定・給与情報に基づく参考値です。銀行の実際の入出金を自動照会する機能ではありません。

## ローカルでの起動とテスト

Node.jsとnpmが必要です。プロジェクトルートで実行します。

```bash
npm ci
npm run check
npm run test
npm run verify:cloud
python3 -m http.server 5173 --directory dist
```

ブラウザで `http://localhost:5173/` を開きます。サーバーの終了は `Ctrl+C` です。`npm run test` はビルドも実行します。

## OneDriveの接続

「設定」からMicrosoftアカウントへ接続し、暗号化保管庫を作成するか既存の保管庫を解除します。Microsoft Entraのアプリ登録には、利用するサイトURLをSPAのリダイレクトURIとして登録し、必要なMicrosoft Graph権限を設定してください。ローカルでは `http://localhost:5173/` を使います。

- 金融データの正本はOneDriveにあります。`src/cloud/` に暗号化・同期・競合解決の実装があります。
- PDF原本、明細、ルール、口座設定は、それぞれ暗号化されたファイルとして保管します。
- 同じ保管庫を別端末から使う場合は、接続先とパスフレーズを一致させます。
- 旧ブラウザ保存データの移行機能は、設定の詳細操作から利用できます。

## 主なディレクトリ

| パス | 役割 |
| --- | --- |
| `public/` | HTML・CSSなどの画面資産 |
| `src/importers/` | カード明細の解析 |
| `src/cloud/` | OneDrive、暗号化、口座・残高・予測などのデータ処理 |
| `src/summary/` | 月別サマリーと残高推移の集計 |
| `src/ui/` | 明細・口座・資産予測などの画面処理 |
| `tests/` | 機能・回帰テスト |
| `scripts/` | ビルド・確認用スクリプト |
| `dist/` | GitHub Pages等へ配信するビルド済みファイル |

## 公開・コミット時の注意

このリポジトリはアプリの**ソースと静的配信物**を管理します。PDF原本、実際のカード明細、給与明細、銀行残高データ、認証トークン、パスフレーズ、復号鍵はGitに追加しないでください。

ビルド・テスト後は、`git diff --cached --check` とステージ対象の内容を確認してからコミットしてください。`local-data/`、`private-data/`、`.env`、PDF/CSVなどは `.gitignore` で除外します。

過去バージョンの技術的な変更記録は、Gitの履歴と既存の `README-v*.md` に保存されています。
