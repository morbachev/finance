# Finance v1.2.9 | 口座残高設定のUI改善

適用元：**Finance v1.2.8**（それ以前に適用する場合はv1.2.8までのパッチを適用）。

## 修正内容

- メインの楽天銀行を独立した「メイン口座」枠へ、現金貯金とNISAを「貯蓄・投資資産」枠へ分離。狭い画面では1列にします。
- 各口座の「OneDriveに保存」ボタンを廃止し、口座残高エリアの下に**1つだけ**「入力した残高をまとめて保存」ボタンを配置。
- 入力済みの口座だけを一括登録。空欄は変更しません。複数口座でも**1回の暗号化Graph保存**で登録するため、途中までしか保存されない状態を防ぎます。
- 保存前にすべての入力値を検証。失敗時は入力を保持し、成功扱いにしません。保存成功後は送信した入力だけをクリアし、確認日時を現在に更新します。
- 日時欄の幅を小さくし、「↻ 現在」ボタンを見出し右側のコンパクトなボタンへ変更。モバイルの折り返し・横はみ出しを修正。
- 保存済みの残高履歴はそのまま維持し、記録削除も従来どおり個別に実行できます。
- 定期入出金の登録・編集・削除、OneDrive暗号化形式、保存パス、パスフレーズ変更・診断機能は変更していません。

## Mac適用

```bash
cd ~/Documents/finance || exit 1
unzip -o ~/Downloads/finance-v129-account-ui-patch.zip -d ~/Documents/finance
npm run check
npm run test
npm run verify:cloud
```

ビルド済みの `dist/` は差分ZIPに含まれます。公開時は `dist/` も反映し、ブラウザで `⌘ + Shift + R` を実行してください。

利用可能なTypeScriptと既存の `dist/vendor` 生成物で検証しています。この環境は `node_modules` の依存物を再インストールできず、ビルドは既存のPDF.js/MSAL vendor出力を保持しました。`dist/`は改変したHTML、CSS、TypeScript出力のみ更新して配布します。
