# Finance v0.8.6 UIパッチ

v0.8.5への上書き差分です。明細解析、エラー判定、暗号化保存、一括取り込み、IndexedDBの保存形式は変更していません。

## 変更内容

1. 取り込み画面・明細管理画面の**共通明細カード**をコンパクト化。カード最低高さを78pxから62px、上下パディングを13pxから9pxへ変更。
2. カード右側の「未保存」「保存済み」「変更あり」の3段目を削除。**金額・照合状態（要確認／暫定明細／照合OK）の2段**に統一。保存対象件数は取込画面下部、保存状態は管理画面の選択中の明細ヘッダーで引き続き確認できます。
3. 明細管理画面の**「請求総額（円）」の入力欄だけ**左揃えに変更。取引明細の金額入力欄は右揃えを維持。
4. 左サイドバーのバージョン表記を `v0.8.6` に更新。

## 適用

```bash
cd ~/Documents/finance
unzip -o ~/Downloads/finance-v086-patch.zip -d ~/Documents/finance
npm run check
npm run test
```

起動済みのローカルサーバーはそのまま使えます。ブラウザで **⌘ + Shift + R** により再読み込みしてください。
