# Finance v1.1.2: 保存・削除の結果表示 / 再読み込み時のタブ内復号

Finance v1.1.1 に重ねる差分パッチです。OneDriveの年別ファイル構造・AES-256-GCM暗号化形式・PBKDF2反復回数・自動マージ・IndexedDB廃止方針は変更しません。

## 変更内容

1. 一括保存、保存済み明細の編集保存、明細削除に、継続表示する操作結果を追加。OneDrive通信中は「保存中／削除中」、成功時は成功メッセージ、失敗時は未保存のままエラーを明示します。明細管理の保存状態には成功時刻を表示します。
2. 保存済み明細の「OneDriveに保存」を、変更がない状態で押しても「保存済み」と応答します。自動保存でも成功時に通知します。
3. 保管庫作成／ロック解除ダイアログに、任意の「このタブでは再読み込み後も解除状態を維持」を追加。**既定はオフ**です。選択時のみ復号用AES鍵を `sessionStorage` に保存し、最大2時間以内の同じタブでのページ再読み込み時に自動解除します。
4. ロックとMicrosoftサインアウト時は一時鍵を削除。Client IDが異なる場合、期限切れ、不正データ、復号失敗時にも削除して通常のパスフレーズ入力へ戻ります。
5. 一時保存するのは **32バイトの復号用AES鍵と暗号ソルト** であり、パスフレーズ・PDF・明細の平文は保存しません。復号鍵はページ内のスクリプトや拡張機能からアクセス可能なため、共有端末や信頼できない環境ではチェックしないでください。ブラウザのタブ復元機能によっては閉じた後もセッション領域が復元されることがあるため、有効期限を設定しています。**IndexedDBはこの機能でも一切使用しません。**

## Macでの適用

```bash
cd ~/Documents/finance || exit 1
unzip -o ~/Downloads/finance-v112-status-session.zip -d ~/Documents/finance
npm run check
npm run test
npm run verify:cloud
```

適用後、ブラウザで `⌘ + Shift + R` で強制再読み込みします。

初回の復号時に「このタブでは再読み込み後も解除状態を維持」にチェックを入れ、通常どおり解除してください。以後同じタブでの再読み込みは、セッションが有効なら自動復号します。チェックしない場合はこれまでどおり毎回入力が必要です。

**注意**：セッション鍵を残したまま明示的に「保管庫をロック」すると、その鍵は削除されます。OneDriveから取り込んだ金融データの暗号化形式や保存ファイルには変更はありません。実際のMicrosoft Graph環境での手動動作検証は利用者側で行ってください。
